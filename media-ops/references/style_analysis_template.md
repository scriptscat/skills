# 风格分析模板

从历史文章中提取写作风格和排版规范，生成可直接指导写作的风格指南。

## 第一部分：写作风格（从纯文本分析）

### 1. 标题风格
- 字数范围
- 是否用数字（「5个方法」）、疑问句、感叹号
- 常见句式模板，列举 3-5 个典型标题

### 2. 开头模式
- 类型：直入主题 / 故事引入 / 数据引入 / 提问引入 / 金句引入
- 平均开头长度（字数）

### 3. 正文结构
- 平均段落长度
- 是否使用小标题分节，小标题风格（编号/关键词/疑问句）
- 是否穿插案例/故事
- 列表使用偏好（有序/无序/不用）
- 全文平均字数

### 4. 语言风格
- 人称（我/我们/第三人称）
- 正式度（书面语/口语化/混合）
- 是否使用 emoji、网络用语
- 修辞偏好（排比、对比、类比等）

### 5. 结尾模式
- 类型：总结归纳 / 号召行动（关注/点赞/转发）/ 开放思考 / 金句收尾

## 第二部分：排版风格（从原始 HTML 分析）

**关键：提取实际使用的 inline style 值，而非猜测。**

### 6. 字体与字号
- 正文 font-size（通常 14-17px）
- 标题 font-size
- 小标题 font-size
- 注释/来源 font-size
- font-family（如有指定）
- letter-spacing（如有）

### 7. 颜色体系
- 正文颜色 color
- 标题颜色
- 强调文字颜色
- 引用文字颜色
- 链接颜色
- 背景色（section/blockquote 等）

### 8. 间距节奏
- 段落 margin-bottom
- 标题 margin-top / margin-bottom
- 行高 line-height
- 段落首行缩进 text-indent（如有）

### 9. 强调方式
- 加粗（bold）
- 变色（什么颜色）
- 背景高亮
- 下划线
- 组合方式

### 10. 引用块样式
- border-left 颜色和宽度
- background 背景色
- padding 内边距
- font-size
- color

### 11. 列表样式
- 有序/无序偏好
- padding-left 缩进量
- li 的 margin-bottom

### 12. 装饰性排版
- 分割线样式（颜色、粗细、margin）
- 是否使用色块标题（带背景的标题）
- 是否使用卡片式排版
- 图片位置偏好和说明文字样式
